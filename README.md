# Spectra Classifier — 光谱数据预处理与聚合物分类

基于 Python 的光谱数据处理与机器学习分类项目：对 6 类聚合物的真实拉曼光谱（PC / PE / PET / PMMA / PP / PVC）进行预处理，并使用 KNN、SVM 与 PCA+KNN 完成定性识别。

## 功能概览

- **`spec_utils.py`** — 光谱预处理工具库：智能表头检测、统一波数网格插值、滑动平均平滑、迭代多项式基线校正、最小-最大归一化、面积归一化、寻峰。
- **`test_spec_utils.py`** — 基于 Pytest 的 11 条单元测试，覆盖边界条件、异常输入与真实数据加载。
- **`classify_spectra.py`** — 基于 Scikit-learn 的分类流水线：KNN、SVM 与 PCA+KNN 对比实验，含混淆矩阵、分类报告、3 折交叉验证，以及 GridSearchCV 自动寻优最佳 K 值。波数范围聚焦拉曼指纹区 400–1500 cm⁻¹。

## 目录结构

## 数据准备

`classify_spectra.py` 按以下结构读取光谱数据（请自行准备）：

```
data/
├── PC/        # 目录名即类别标签
├── PE/
├── PET/
├── PMMA/
├── PP/
└── PVC/
```

每个类别目录下放置若干 `.csv` 文件，每个文件两列：`波数(cm⁻¹), 强度`，可有可无表头。程序会自动检测并跳过表头。

## 快速开始

### 1. 环境准备

需要 Python 3.9+，建议使用 Anaconda 或 venv：

```bash
pip install -r requirements.txt
```

### 2. 运行单元测试

```bash
pytest test_spec_utils.py -v
```

预期输出：`11 passed`。

### 3. 运行分类建模

```bash
python classify_spectra.py
```

脚本会输出：
- KNN：测试集准确率、混淆矩阵、分类报告、3 折交叉验证得分；
- PCA+KNN：3 折交叉验证得分；
- GridSearchCV：在 k ∈ {3,5,7,9,11} 中自动搜索最佳 K 值；
- SVM（线性核）：测试集准确率、混淆矩阵、分类报告、3 折交叉验证得分。

## 结果

| 方法 | 测试集准确率 | 3 折交叉验证平均得分 |
|---|---|---|
| KNN（引入基线校正前） | — | 0.8573 |
| KNN（引入基线校正后） | 0.9706 | 0.9561 |
| SVM（线性核） | 1.0000 | — |
| PCA + KNN（K=3） | — | 0.9825 |

> 上表基于 400–4000 cm⁻¹ 波数范围的早期结果。当前代码已切换至拉曼指纹区 400–1500 cm⁻¹，请用完整光谱数据运行 `classify_spectra.py` 获取更新后的指标。

### 关键发现

通过可视化原始光谱，发现 PC 与 PET 因基线漂移导致 KNN 分类混淆。引入迭代多项式基线校正后，误判消失，交叉验证平均得分从 **0.8573 提升至 0.9561**——高质量的数据预处理比盲目调参更重要。

## 技术细节

- 统一波数网格：聚焦拉曼指纹区，将 400–1500 cm⁻¹ 插值对齐到 1000 个点，保证特征维度一致且剔除指纹区外噪声。
- 预处理流水线：`平滑去噪 → 基线校正 → 最小-最大归一化`。
- 基线校正原理：迭代加权多项式拟合，对高于基线的特征峰赋予极小权重，拟合出背景基线后扣除。
- 调参：PCA 保留 95% 方差；KNN 通过 GridSearchCV 在 k ∈ {3,5,7,9,11} 中搜索最佳值。
